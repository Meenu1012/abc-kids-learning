# 🌈 ABC Kids – Interactive Learning App

ABC Kids is a fun and interactive React web application designed to help children learn alphabets, numbers, and colors in an easy and enjoyable way.

## 🚀 Features

- 🔤 Learn A to Z
- 🔠 Capital and lowercase letters
- 🍎 Alphabet examples with emojis
- 🔊 Pronunciation using browser speech
- 🔢 Learn numbers from 1 to 10
- 🎨 Learn different colors
- 🎯 Interactive ABC Quiz
- ⭐ Quiz score
- 🏆 Quiz result
- 🔄 Play Again option
- 🏠 Easy navigation
- 📱 Mobile-friendly design

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Web Speech API
